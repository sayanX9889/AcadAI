Frequently Asked Questions

A few quick answers about feedback.

Will my feedback affect my academic records?

No. Feedback is separate from your academic profile and is intended only to improve the AcadAI experience.

Can I report an incorrect AI recommendation?

Yes. Select the relevant feature and explain what was incorrect. If possible, mention the course or recommendation involved.

Can I suggest a new feature?

Absolutely. Use the feedback box to describe the feature and explain how it would help students.
